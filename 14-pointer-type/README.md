# 1.指针

> 三个概念：指针地址、指针类型、指针取值

## 1.1.Go语言中的指针
Go语言中函数传参都是值拷贝，所以在需要修改值时，我们可以使用指针变量。传递数据使用指针，无须拷贝数据。
> `&`(取地址) 和 `*`(根据地址取值)

### 1.1.1.指针地址和指针类型
每个变量在运行时都有一个地址，代表变量在内存中的位置。使用`&`字符放在变量前对变脸进行取地址操作
Go语言中的值类型（int uint float bool string array struct）都有对应的指针类型，如*int *uint

```
ptr := &v
```

```
v: 代表被取地址的变量，类型为T
ptr: 用于接收地址的变量，ptr 的类型就是*T，称做T的指针类型。*代表指针
```

### 1.1.2.指针取值
对普通变量使用&操作符取地址后会获得这个变量的指针，然后可以对指针使用*操作，也就是指针取值。

### 1.1.3.空指针
一个指针被定义后没有分配到任何变量时，它的值为nil

### 1.1.4.new 和 make
对于引用类型的变量，我们在使用时不仅要声明它，还需要为它分配内存空间，对于值类型的声明时不需要分配内存空间，因为值声明时会默认分配好内存空间的。要分配内存需要使用new 和make

### 1.1.5.new

```
func new(Type) *Type
```
- new 只接收一个参数，这个参数是一个类型
- *Type 表示类型指针，new 函数返回一个指向该类型内存地址的指针

### 1.1.6.make
- make 也是用于分配内存的，但是只可以用于slice map chan的内存创建
- 返回的类型是这三个值，而不是指针
```
func make(t Type, size, ...IntegerType) Type
```

### 1.1.7.new和make的区别
- 二者都是用于内存分配的
- make 只用于 slice map chan的初始化，返回的是这三个引用类型本身
- new 用于类型的内存分配，内存的值为对应的零值，返回的是只指向类型的指针
